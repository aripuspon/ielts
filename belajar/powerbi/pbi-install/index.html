Instal Power BI Desktop

Unduh aplikasi desktop gratisnya dan buka untuk pertama kali.

Langkah demi langkah·5 menit·Materi 1 dari 21 Gratis

Power BI Desktop adalah aplikasi gratis dari Microsoft untuk membuat laporan dan dashboard. Di materi ini Anda cukup memasangnya, membukanya, lalu masuk ke halaman laporan kosong. Yang dibutuhkan: laptop atau PC Windows 10/11 dan koneksi internet.

Langkah demi langkah

  1. 1

    Langkah 1: Cara paling mudah: buka aplikasi Microsoft Store di Windows, cari Power BI Desktop, lalu klik Get (atau Install).

    Tips: Versi Microsoft Store ter-update otomatis tiap bulan. Cara lain: buka powerbi.microsoft.com → Products → Power BI Desktop → Download, lalu pilih file PBIDesktopSetup_x64.exe.

    Hati-hati: Power BI Desktop hanya tersedia untuk Windows. Pengguna Mac bisa memakai Windows lewat Parallels/mesin virtual, atau komputer kantor/kampus.

  2. 2

    Langkah 2: Tunggu sampai terpasang (ukurannya ratusan MB, pastikan internet stabil). Kalau memakai file installer: jalankan filenya, centang I accept the terms, lalu klik Next sampai Finish.

  3. 3

    Langkah 3: Buka Power BI Desktop dari menu Start. Di layar Home, klik Blank report (nomor 1 di gambar) untuk membuka halaman laporan kosong.

    Tips: Di versi lama, yang muncul adalah jendela sambutan kecil. Cukup tutup dengan tombol X.

  4. 4

    Langkah 4: Sign in (nomor 2) dengan akun kantor atau kampus. Opsional sekarang, tetapi wajib nanti saat publish ke Power BI Service.

    Hati-hati: Akun pribadi seperti Gmail, Yahoo, atau Outlook.com tidak bisa dipakai untuk publish. Gunakan email kantor atau kampus (mis. nama@perusahaan.co.id).

Cek hasil Anda

Anda melihat halaman putih kosong bertuliskan Add data to your report. Itu tandanya Power BI siap dipakai. Klik Tandai selesai, lalu lanjut ke tur antarmuka.
